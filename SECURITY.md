# Security policy

Cyberwall is a security tool under active development. Do not rely on pre-alpha builds to
protect production systems.

To report a vulnerability privately, use [GitHub's private vulnerability reporting](https://github.com/omermindivanli/cyberwall/security/advisories/new).
Please do not open a public issue for an unpatched vulnerability. If private reporting is not
available, contact the repository owner through their GitHub profile without including secrets.

Reports are acknowledged as soon as practical. We will coordinate a fix and disclosure with the
reporter. Please use synthetic data and systems you own when reproducing issues.
